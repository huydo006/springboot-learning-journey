# Session Logs

Mỗi buổi học tạo một file riêng theo mẫu `99_TEMPLATES/SESSION_TEMPLATE.md`.

## Quy tắc đặt tên

`02_SESSIONS/YYYY/WEEK_XX/SESSION_YY.md`

Ví dụ: `02_SESSIONS/2026/WEEK_01/SESSION_01.md`

Một session nên ghi:
- Mục tiêu và thời lượng.
- Kiến thức thực sự học.
- Bài tập và kết quả.
- Mức độ hiểu từng khái niệm.
- Điểm mạnh, điểm yếu, lỗi đáng chú ý.
- Câu hỏi cần ôn và đề xuất buổi tiếp theo.

Không cần chép lại toàn bộ giáo trình.
