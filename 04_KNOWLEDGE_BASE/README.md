# Knowledge Base

Chỉ lưu ghi chú kiến thức đã được hiểu và kiểm chứng. Không dùng thư mục này làm nhật ký buổi học.

Mỗi ghi chú nên có:
- Concept / definition.
- Why it matters.
- How it works.
- Example.
- Common pitfalls.
- When to use / when not to use.
- Related sessions and sources.
- Last reviewed date.
