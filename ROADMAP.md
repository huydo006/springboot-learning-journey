# Roadmap Spring Boot – 16 tuần

## Hồ sơ đầu vào

- Java Core: Khá ổn; có thể tự viết OOP, Collections và xử lý logic.
- Spring Boot: Đã thực hành CRUD, JPA, DTO và MapStruct cơ bản.
- Thời gian: 12–15 giờ/tuần.
- Mục tiêu: Chuẩn bị kiến thức và project để ứng tuyển thực tập Backend Java.

## Phân bổ thời gian gợi ý

| Hoạt động | Giờ/tuần |
|---|---:|
| Học và đọc tài liệu | 3 |
| Bài tập thực hành | 5 |
| Phát triển project | 3–4 |
| Ôn tập, kiểm tra, ghi chép | 1–3 |

## Lộ trình

| Tuần | Chủ đề | Đầu ra chính |
|---:|---|---|
| 01 | Spring IoC, DI, Bean | Giải thích và thực hành quản lý Bean |
| 02 | Spring Boot fundamentals, request lifecycle | REST API nhỏ, profiles, interceptor |
| 03 | JPA/Hibernate internals | Hiểu persistence context, dirty checking, transaction |
| 04 | Query và tối ưu truy vấn | JPQL, pagination, nhận diện N+1 |
| 05 | Database design và transaction | ERD, migration, xử lý cập nhật đồng thời cơ bản |
| 06 | DTO và MapStruct nâng cao | Nested mapping, update mapping |
| 07 | Validation và exception handling | Global error response |
| 08 | REST API design | API nhất quán, tìm kiếm, Swagger |
| 09 | Spring Security fundamentals | Hiểu Security Filter Chain và password hashing |
| 10 | JWT authentication | Register/login và bảo vệ endpoint |
| 11 | Authorization | Role/permission và kiểm soát quyền truy cập |
| 12 | Unit testing | JUnit 5, Mockito, test Service |
| 13 | Integration testing | Test API và persistence |
| 14 | Architecture và clean code | Refactor, SOLID, logging |
| 15 | Docker và deployment | Chạy ứng dụng cùng database bằng Docker |
| 16 | Portfolio và phỏng vấn | Repo hoàn chỉnh, README, demo, trình bày thiết kế |

## Cổng đánh giá theo giai đoạn

### Sau tuần 2 – Spring Core
- [ ] Giải thích IoC, DI, Bean và Auto Configuration.
- [ ] Tự tạo và inject Bean.
- [ ] Giải thích được luồng request cơ bản.

### Sau tuần 5 – JPA và Database
- [ ] Giải thích persistence context, dirty checking và transaction.
- [ ] Thiết kế được ERD cho nghiệp vụ đặt phòng.
- [ ] Viết query, pagination và xử lý N+1 cơ bản.

### Sau tuần 8 – REST API
- [ ] Thiết kế API có DTO, validation và error handling.
- [ ] Mapping được dữ liệu lồng nhau và cập nhật entity.
- [ ] Có tài liệu API.

### Sau tuần 11 – Security
- [ ] Xây dựng authentication.
- [ ] Phân quyền endpoint và dữ liệu theo người dùng.
- [ ] Giải thích được luồng xác thực.

### Sau tuần 13 – Testing
- [ ] Viết được unit test cho business logic.
- [ ] Viết được integration test cho luồng API chính.

### Sau tuần 16 – Internship readiness
- [ ] Project có thể chạy theo hướng dẫn.
- [ ] Có README, ERD, API docs và Git history rõ ràng.
- [ ] Tự giải thích được kiến trúc, quyết định kỹ thuật và giới hạn hiện tại.
- [ ] Có thể xử lý câu hỏi Java, SQL, Spring Boot ở mức thực tập.

## Quy tắc điều chỉnh

Roadmap là định hướng, không phải lịch cứng. Nếu một chủ đề chưa đạt tiêu chí, chuyển trạng thái thành `Needs Review`, bổ sung buổi ôn và điều chỉnh tuần kế tiếp. Không học chủ đề nâng cao chỉ để chạy kịp lịch.
